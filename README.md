# 🧮 Ultra Calculator

An all-in-one calculator with Standard, Scientific, Programmer modes!

## Features
- **Standard Mode**: Basic arithmetic
- **Scientific Mode**: Trig functions, logs, square root
- **Modern UI**: Beautiful dark theme with gradients
- **Responsive**: Works on mobile and desktop
- **Keyboard Support**: Full keyboard input

## Quick Start
1. Open `index.html` in your browser
2. Start calculating!

Enjoy! 🚀
